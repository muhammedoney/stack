# Firmware

Sahibi `gomulu-yazilim`. Pin ve zamanlayıcı atamalarının tek kaynağı `docs/pin-haritasi.md`.

| Klasör | İçerik |
|---|---|
| `esc/` | EFM8BB21 ESC: Bluejay / BLHeli_S düzen eşlemesi, yükleme notları (C2, BLHeli geçişi) |
| `fmu/` | STM32F405: Betaflight unified target config, yükleme (USB DFU) |

Durum (2026-11-06): boş. Önce esc55a port atamasının bilinen bir Bluejay düzenine uyup uymadığı kontrol edilecek (`docs/inceleme.md` §2.4).
