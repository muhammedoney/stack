# Sistem gereksinimleri (SYS)

Alt sistemler: **SİS** sistem geneli, **FMU** uçuş kontrol kartı, **ESC** ESC kartları, **GÜÇ** besleme/BEC, **YAZ** yazılım, **ARA** arayüz/konnektör, **MEK** mekanik/çevre.

> 2026-11-06: Boş. SOR-001…008 cevaplarından sonra türetilecek; Altium tasarımından geri çıkarılacak maddeler `Kaynak: Altium` ile işaretlenecek.
