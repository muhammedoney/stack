# Test

Sahibi `test-muhendisi`. Doğrulama maddeleri (`docs/gereksinimler/dogrulama.md`) için kanıt üretir.

| Klasör | İçerik |
|---|---|
| `analiz/` | Hesap betikleri (Python): MOSFET kayıp/ısı, bakır akım, shunt aralığı, BEC bütçesi, bölücüler |
| `prosedur/` | Kart gelince uygulanacak tezgâh test prosedürleri (akım sınırlı ilk açılış, yük/itki tezgâhı, ısı) |
| `sonuc/` | `DOG-xxx.md` sonuç raporları: tarih, yöntem, girdi, çıktı, geçti/kaldı |

`testedilebilirlik.md` (oluşturulacak): kart öncesi test noktası / programlama pedi / LED isteği listesi.
